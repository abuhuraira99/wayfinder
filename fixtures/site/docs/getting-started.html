Getting started with the Halcyon Edge agent

The Edge agent runs next to your Cirrus Hub and buffers readings when the uplink drops.

Requirements

  • Linux kernel 5.10 or later
  • 512 MB of free memory

Install

curl -fsSL https://get.halcyon-instruments.example/edge | sh

Configuration

SettingDefaultDescription
listen_port8443TCP port the agent listens on
buffer_hours72Hours of readings kept while offline
log_levelinfoOne of debug, info, warn, error
